# MYTC v1.0.20

- Adds WinRAR **Extract to named folder (R)**.
- Allows different workspace instances to run simultaneously while retaining same-workspace forwarding.
- Gives each workspace instance a separate taskbar identity and session file.
- Adds workspace taskbar icon selection with initial `1` and `W` badge variants.
- Migrates existing workspace and context-menu configuration without replacing user customization.
