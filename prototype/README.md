# MYTC 交互原型

直接双击 `index.html`，或用浏览器打开。

这是开发前交互验证原型，不会读取、复制、移动或删除真实文件。

可验证：

- 点击四个窗格，观察“活动窗格/目标窗格”切换。
- 拖动中间横向、纵向分隔线。
- 点击窗格右上角按钮临时最大化并恢复。
- 切换标签；带锚点的固定目录标签再次点击会回到固定目录。
- 使用盘符下拉菜单和地址栏切换路径。
- 点击名称、修改日期、类型、大小进行排序。
- 右键文件行查看自定义菜单示意。
- 按 F5/F6 查看目标窗格操作提示。
- 按 Ctrl+D，再按 P，体验连续按键提示。
- 在窗格之间拖动文件行，体验复制/移动提示。
