# MYTC 第一版需求基线

状态：第一版已冻结；生产版扩展已确认  
日期：2026-07-28

## 1. 产品定位

MYTC 是一个供用户个人使用的 Windows 四窗格资源管理器。它作为 Windows 资源管理器的辅助工具；可由用户主动、可逆地配置 Win+E 启动 MYTC，但不接管资源管理器内部的普通文件夹、磁盘打开行为。

产品的核心支点是让四类常用目录同时可见，减少标书制作和视频制作过程中反复打开、关闭及切换资源管理器窗口的成本。

## 2. 运行环境与交付

- 支持 Windows 10/11 64 位。
- 以免安装绿色便携版交付。
- 快捷键只在 MYTC 获得焦点时生效，不注册系统全局热键。
- 用户配置和工作区数据应能随便携目录迁移。

## 3. 主界面

### 3.1 四窗格

- 默认布局为 2×2。
- 四个窗格相互独立。
- 用户可以拖动横向、纵向分隔线调整窗格大小。
- 可以临时最大化活动窗格，并一键恢复四窗格布局。
- 结构上保留未来增加单窗格、双窗格和自定义布局的可能。

### 3.2 每个窗格的组成

每个窗格至少包含：

1. 标签栏。
2. 导航按钮。
3. 当前地址栏。
4. 盘符快速切换下拉菜单。
5. 文件详细信息列表。
6. 用于识别活动状态和复制移动目标状态的视觉标记。

盘符下拉菜单应动态列出当前可用的本地盘、移动盘和映射盘，例如 C:、D:、O:、T:。

## 4. 标签

### 4.1 通用属性

每个标签至少保存：

- 唯一标识
- 所属窗格
- 自定义显示标题
- 当前目录
- 是否启用固定目录模式
- 固定目录路径
- 前进、后退浏览历史

### 4.2 标题

- 用户可以自定义标签显示标题。
- 自定义标题设置后保持不变，不随当前路径变化。
- 窗格地址栏始终显示当前真实路径。
- 未设置自定义标题时，可以使用当前文件夹名作为回退标题。

### 4.3 普通标签

- 标签记录最后一次操作位置。
- 切换回来时继续显示上次位置。
- 软件退出后，由工作区状态保存该位置，并在下次启动时恢复。

### 4.4 固定目录标签

- 用户可以将标签设置为固定目录标签。
- 用户可以在标签内临时浏览固定目录以外的位置。
- 每次点击或重新激活该标签时，立即回到预设固定目录。
- 固定目录概念不等同于“标签置顶或禁止关闭”。

### 4.5 标签管理

第一版支持：

- 新建标签
- 关闭标签
- 自定义标题
- 标签排序
- 固定目录/取消固定目录
- 恢复最近误关闭的标签

## 5. 工作区与状态恢复

- 软件启动时恢复上次关闭时的窗口、四窗格比例、标签、标题和当前目录。
- 支持把工作区方案保存到本地。
- 支持加载不同工作区方案。
- 支持管理工作区方案：删除、导入、导出；同名导入不得覆盖已有方案。
- 最后一次载入或保存的命名工作区作为默认启动方案；支持 `/方案名` 与 `--workspace 方案名` 命令行启动指定方案。
- 工作区配置采用便携数据文件保存。
- 未来可以基于同一机制扩展更多布局。

每个工作区保存：

- 四窗格布局与比例
- 每个窗格的全部标签
- 标签顺序及自定义标题
- 普通标签的最后目录
- 固定目录标签及其固定路径
- 每个标签的排序字段和升降序
- 当前活动窗格和目标窗格

快捷键、右键菜单和软件主题属于全局设置，不随工作区切换。

操作工具栏、工作区工具栏和设置工具栏均可分别显示或隐藏，且显示状态属于全局设置。

活动文件窗格支持名称片段快速定位：连续输入英文或输入法确认后的中文名称，应选中匹配项目；文件夹优先于普通文件，同类中名称开头优先、名称中间片段其次；输入缓冲超时后自动开始下一次查询。

当名称片段命中多个项目时，↑ / ↓ 应在当前匹配集合内循环选择；鼠标选择、目录导航或下一次文字输入会重建该集合。

固定目录标签的显示标题应来自固定时设置的自定义标题或固定目录名，不随标签内临时浏览的子目录变化；普通标签显示标题始终跟随当前目录名。

同一目录内右键拖放不应被视为无操作：必须提供复制到本处和在当前位置创建快捷方式；仅不提供无意义的移动到本处。子目录返回父目录后，应重新选中并聚焦该子目录。

## 6. 文件显示与导航

- 文件列表使用详细信息模式。
- 至少提供名称、修改日期、类型、大小等列。
- 点击列标题可以按对应字段升序或降序排列。
- 文件夹和文件的排序规则应保持稳定。
- 支持进入目录、上级目录、后退、前进、刷新和直接输入路径。
- 双击文件时使用 Windows 系统默认关联程序打开。
- 单个目录通常少于 100 个对象，但实现不应人为限制更大目录。

## 7. 文件操作

第一版按 Windows 资源管理器基本能力提供：

- 新建文件夹
- 打开文件
- 复制
- 剪切
- 粘贴
- 移动
- 重命名
- 删除
- 刷新
- 多选

复制移动采用以下基础模型：

- 当前活动窗格为源窗格。
- 最近使用的另一个窗格为目标窗格。
- 界面必须明显显示源窗格和目标窗格。
- 常用路径包括左上到右上，以及右上到右下。

必须支持：

- 窗格之间拖放文件。
- 与 Windows 桌面、资源管理器及其他支持拖放的软件互相拖放。
- Windows 系统剪贴板 Ctrl+C、Ctrl+X、Ctrl+V。

## 8. 路径范围

第一版支持：

- 本地磁盘
- U 盘及移动硬盘
- 映射网络盘
- 普通 UNC 网络路径
- 作为普通文件系统目录呈现的 OneDrive 内容

第一版暂不把以下对象实现为可浏览虚拟目录：

- ZIP、RAR 等压缩包
- FTP/SFTP
- WSL 虚拟文件系统
- 插件提供的远程目录

## 9. 快捷键

### 9.1 默认方案

- 把 Windows 资源管理器常用快捷键和 Total Commander 常用快捷键合并为同一个默认方案。
- 同一个命令允许绑定多个快捷键。
- Windows 剪贴板式操作与 Total Commander 目标窗格式操作同时存在，但保持不同的内部命令语义。
- 例如 Ctrl+C 表示“复制到系统剪贴板”，F5 表示“把选择项直接复制到目标窗格”；两者不能被错误地实现成完全相同的命令。

### 9.2 自定义能力

- 用户可以逐项修改、增加和删除命令绑定。
- 支持单键。
- 支持带修饰键的组合键。
- 支持连续按键序列，例如先按 Ctrl+D，再按后续按键。
- 需要检测重复绑定、前缀冲突和不可用按键。
- 连续按键等待期间应提供可见提示。
- 第一版不要求导入导出快捷键配置。

## 10. 右键菜单

- 右键菜单需要支持自定义。
- 支持控制内置菜单项的显示、隐藏和排序。
- 支持加入“使用某程序打开”等外部程序命令。
- 自定义命令支持当前文件、选中文件、当前目录等参数变量。
- 第一版不强制嵌入完整的 Windows Shell 原生右键菜单。

## 11. 安全策略

- 普通删除进入回收站。
- 永久删除需要明确操作及二次确认。
- 文件名冲突时提供覆盖、跳过、重命名等选择。
- 批量操作显示进度及当前对象。
- 部分失败时列出失败对象及原因。
- 第一版不自行实现完整文件操作撤销系统；仅提供当前 MYTC 会话内最近一次“移到回收站”的安全还原。

## 12. v0.1.x 第一版暂不纳入

以下是早期第一版边界；“默认文件管理器”和自动更新两项已由第 14 节的用户新授权取代。

- 注册为 Windows 默认文件管理器
- 系统后台全局快捷键
- 快捷键配置导入导出
- FTP/SFTP
- 压缩包虚拟目录
- 插件系统
- 文件内容对比
- 面向公众的自动更新及账户系统

## 13. 第一版验收场景草案

1. 启动绿色版程序。
2. 自动恢复上次的 2×2 四窗格工作区。
3. 右下窗格通过盘符菜单快速切换到 T: 或 O:。
4. 左上和右上分别打开项目目录与素材/AI 输出目录。
5. 通过地址栏确认每个窗格的当前真实路径。
6. 点击自定义标题的固定目录标签，标签进入预设目录。
7. 普通标签切走再回来后保留最后浏览位置。
8. 使用鼠标拖放、Ctrl+C/Ctrl+V 或 TC 风格快捷键在左上与右上之间复制文件。
9. 在右上与右下之间移动文件。
10. 点击名称、修改日期、类型和大小列完成排序。
11. 关闭并重新启动软件，窗格比例、标签、标题和目录状态正确恢复。

## 14. v1.0.0 生产版扩展

### 14.1 Win+E 启动 MYTC

- 用户先把完整程序放到本机固定磁盘目录，例如 `E:\port\MYTC`。
- 配置只写入当前用户注册表，不要求管理员权限。
- 普通文件系统目录和磁盘的默认打开动作始终保持 Windows 资源管理器；MYTC 只额外注册“在 MYTC 中打开”动词。
- Win+E 由登录后启动的独立轻量桥接进程处理。
- 主程序采用单实例；新目录请求转交给已运行窗口的活动窗格。
- 不修改 `HKLM\...\Winlogon\Shell`，不替换 `explorer.exe`，不接管桌面、任务栏和登录外壳。
- 独立维护工具必须同时提供 Win+E 启用、状态和停用能力；旧版文件夹接管的原注册表值保存在 `%LocalAppData%\MYTC\shell`，首次正常启动自动迁移。
- 注册、恢复和测试都不得绕过 Windows 安全策略或强制结束其他会话的进程。

### 14.2 便携升级

- 菜单允许选择 `MYTC-vX.Y.Z-win-x64.zip`。
- 默认选包目录为 `T:\mytc-updates`，但升级 ZIP 可以来自其他可读路径。
- 升级包必须包含产品、架构、版本及逐文件长度/SHA-256 清单。
- 拒绝路径穿越、重复路径、未列入清单的文件、错误产品/架构、非更高版本，以及任何 `data` 内容。
- 主程序先解压到 `%LocalAppData%\MYTC\updates\staging`，随后启动安装目录外的单文件更新器并正常退出。
- 更新器等待主程序和 Win+E 桥接退出，备份原受管文件，逐文件替换并再次校验；失败时恢复已更改文件。
- 安装目录中的 `data` 永不覆盖。升级成功后自动重启主程序和已注册的 Win+E 桥接。
- Win+E 配置和就地升级只允许本机固定磁盘安装目录，不从映射盘或 UNC 路径直接运行。

### 14.3 恢复与交付

- 即使 `MYTC.exe` 无法启动，也能直接运行 `MYTC.Maintenance.exe` 停用 Win+E 桥接。
- `v1.0.0` 是首次带内置升级功能的版本，从 `v0.1.7` 迁移需手动复制一次；后续版本通过程序内升级。
- 版本 ZIP 固定投递到 `T:\mytc-updates`；可直接复制安装的完整目录使用按版本命名的独立位置，避免覆盖正在运行的旧版。
