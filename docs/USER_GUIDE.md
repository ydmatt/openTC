# MYTC v1.0.0 使用说明

## 启动

1. 把完整压缩包解压到本机固定磁盘目录，例如 `E:\port\MYTC`；不要只复制 `MYTC.exe`。
2. 双击 `MYTC.exe`。这是绿色自包含版本，不要求电脑预装 .NET。
3. 配置自动保存在程序旁的 `data/` 目录。备份或迁移时复制整个 MYTC 文件夹即可。
4. 不要从 T 盘、映射网络盘或 UNC 共享直接运行生产版；T 盘只用于存放升级 ZIP。

从 `v0.1.7` 迁移时，先关闭旧 MYTC，再把旧目录中的 `data` 复制到新安装目录。`v1.0.0` 是首次带程序内升级功能的版本，所以这一步只需手动做一次。

## 配置或停用 Win+E 启动 MYTC

1. 先确认 MYTC 已位于不会再移动的本机目录。
2. 选择“选项 → Win+E 启动 MYTC 设置”。
3. 点击“启用 Win+E 启动 MYTC”。

启用后，Win+E 会启动 MYTC；但 Windows 资源管理器中双击文件夹、按 Enter、磁盘打开等操作仍由 Explorer 管理，二者互不干扰。

如需恢复 Win+E 的系统默认行为，直接运行安装目录中的 `MYTC.Maintenance.exe`，点击“停用 Win+E 桥接”。即使 `MYTC.exe` 无法启动，也可独立执行。旧版文件夹关联的注册前备份保存在 `%LocalAppData%\MYTC\shell\registration-backup.json`，新版本会在首次正常启动时自动迁移。

## 从升级包升级

1. 把新版 `MYTC-vX.Y.Z-win-x64.zip` 放到 `T:\mytc-updates`。
2. 在 MYTC 中选择“选项 → 从升级包升级”。
3. 选择 ZIP 并确认目标版本。

程序会先把升级包复制/解压到本机并校验每个文件，随后正常退出。安装目录外的更新器会备份旧程序、替换并再次校验；失败时自动回滚，成功后自动重启。安装目录中的 `data` 不会被升级包覆盖。

## 四窗格与目标窗格

- 蓝色边框表示活动窗格，橙色边框表示目标窗格。
- 点击另一个窗格后，新窗格成为活动窗格，原活动窗格成为目标窗格。
- `F5` 把活动窗格所选项目复制到目标窗格，`F6` 执行移动。
- 每个窗格可独立调整盘符、输入路径、后退、前进、上级、刷新和临时最大化。
- 文件和文件夹使用 Windows 当前系统的默认关联图标。

## 顶部菜单与操作工具栏

- 顶部保留传统“文件、编辑、查看、选项、信息”菜单，常用文件操作和设置都可以从菜单进入。
- “复制到目标 F5、移动到目标 F6、新建目录 F7、回收站删除 F8、重命名 F2”等按钮属于操作工具栏。
- 新安装默认隐藏操作工具栏；在“查看 → 操作工具栏”中可以随时显示或关闭，选择会自动保存。

## 标签

- `+` 新建标签，`↶` 恢复刚关闭的标签。
- 双击标签栏空白处也可以新建标签。
- 鼠标中键点击标签可直接关闭。
- 右键标签可设置标题、固定目录、关闭或调整顺序。
- 右键标签选择“复制标签到目标窗格”，会把标题、当前目录、固定目录、前进/后退历史和排序状态完整复制到目标窗格，并在目标窗格新增同样的标签。
- 按住标签拖到另一个窗格后释放，也会在目标窗格复制一个完整标签；源标签保留。
- 右键标签只会弹出菜单；选择其中的“固定当前目录”后，才会使用当前目录名称作为标题并固定到该目录，且不再弹设置窗口。
- 普通标签回到最后浏览的位置。
- 固定标签允许临时浏览其他位置；切走后再次点击该标签，会回到设置的固定目录。
- 右上角“标签菜单设置”可隐藏、改名、调整标签右键菜单顺序，支持恢复默认和保存/载入命名方案。

## 工作区

- “保存工作区”保存四个窗格的比例、标签、目录、排序及活动/目标窗格。
- 从顶部下拉菜单选择名称并点击“载入”即可切换。
- “文件 → 管理工作区方案”可以导入、导出或删除命名工作区；删除工作区不会删除其中任何真实文件。
- 导入与已有方案同名的 JSON 时，MYTC 自动创建新名称（如 `work (2)`），不会覆盖原方案。
- 加载或保存一个命名工作区后，它会成为下次正常启动时优先载入的默认工作区；若该方案已被删除，则回退到上次会话。
- 可给快捷方式添加工作区参数：`MYTC.exe /work`，或使用 `MYTC.exe --workspace work`。需要同时打开目录时可使用 `MYTC.exe --workspace work --open "E:\\项目"`。
- 正常退出时仍自动保存本次会话，作为没有指定默认工作区时的回退。

## 工具栏显示

- “查看”菜单可分别显示或隐藏“操作工具栏”“工作区工具栏”“设置工具栏”。
- 工作区工具栏包含方案下拉列表、载入、保存与管理入口；设置工具栏包含快捷键、右键菜单与标签菜单设置。
- 三项显示状态会自动保存，快速连续切换也不会造成设置文件互相占用。
- 当工作区工具栏与设置工具栏都隐藏时，顶部“4 MYTC”边栏也会自动折叠，不会留下无功能的黑色空栏。

## 直接输入定位

- 文件列表处于活动窗格时，直接连续输入名称片段可快速选中对应项目。例如在 `T:\` 输入 `nfc`，会优先选中 `NFCdaka` 文件夹；文件夹名为 `2026甘肃` 时，输入 `甘肃` 也可定位。
- 输入间隔超过约 1.2 秒会开始一次新的定位；输入的片段没有匹配项时，也会自动从刚输入的字符重新匹配。
- 中文目录请用输入法完成候选词后继续输入或确认，MYTC 会按实际中文名称匹配。MYTC 会先在文件夹中匹配，再考虑普通文件；同类中名称开头的匹配优先于名称中间片段。
- 当有多个匹配项目时，输入会定位到第一项；随后按 ↑ / ↓ 可在本次匹配结果中循环切换。鼠标重新选择、导航到其他目录或重新输入会开始新的匹配。

## 右键拖放与返回上级

- 在同一窗格内右键按住选中文件或文件夹并拖动后释放，会显示“复制到此处”和“在当前位置创建快捷方式”。前者会按现有重名规则创建备份副本，后者在当前目录创建快捷方式文件。
- 拖到其他窗格时，右键菜单仍提供复制、移动和创建快捷方式；同目录中“移动到此处”不显示，因为它没有实际作用。
- 进入某个子目录后按 Backspace 回到上级目录，列表会选中并聚焦刚才进入的子目录，而不是跳回第一项。

## 默认快捷键

| 操作 | 快捷键 |
|---|---|
| 复制到目标窗格 | `F5` |
| 移动到目标窗格 | `F6` |
| 新建文件夹 | `F7` |
| 移到回收站 | `Del` / `F8` / `Ctrl+D` |
| 永久删除 | `Shift+Del` / `Shift+F8` |
| 重命名 | `F2` |
| 剪贴板复制/剪切/粘贴 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| 激活四个窗格 | `Ctrl+1` ～ `Ctrl+4` |

| 返回上级目录 | `Backspace` |

### 修改快捷键

1. 点击右上角“快捷键设置”。
2. 双击一行，或选中后点击“录入/修改”。
3. 直接按下新单键或组合键，例如 `Del`、`Ctrl+Shift+T`；录入成功后窗口会自动关闭。
4. 要录入 `Ctrl+K, P` 这样的连续按键，先勾选“录入连续按键”，依次按下各段，再点击“完成”。运行时连续按键间隔为 1.5 秒。由于默认 `Ctrl+D` 已直接执行删除，不能同时再把它作为连续按键的第一段；如确需 `Ctrl+D, P`，先移除单独的 `Ctrl+D` 绑定。
5. 同一功能需要多个快捷键时，从左下角选择功能并点击“为此功能添加”；每条快捷键会单独占一行。

“文字编辑”仍可用于高级手工输入。“恢复默认”会恢复内置 Windows + Total Commander 合并方案。顶部可以把当前设置保存为命名方案，或载入以前保存的方案；最后点击“保存并应用”才会更新当前生效设置。

## 文件操作与安全

- 本地盘普通删除进入 Windows 回收站；映射共享盘和 UNC 共享会移动到同一共享根目录下由 MYTC 管理的隐藏 `.MYTC-RecycleBin`，避免共享盘无法撤销。永久删除一定会再次确认。
- 文件右键菜单的“撤销删除”可还原当前 MYTC 会话内最近一批移到回收站的项目；退出软件后不保留撤销栈。
- 不要手动移动或删除共享盘上的 `.MYTC-RecycleBin`；MYTC 文件列表会自动隐藏它。
- 遇到同名项目时可选择“两者保留”“跳过”“替换”或取消。
- “替换”会先删除同名目标；不确定时优先选择“两者保留”。
- 工具栏显示操作进度，可取消；右下角“失败”可查看失败项目。
- 拖入窗格默认复制，按住 `Shift` 拖入时移动。
- `Ctrl+C`/`Ctrl+X`/`Ctrl+V` 使用 Windows 文件剪贴板，可与资源管理器互通。
- 在同一目录选择文件后按 `Ctrl+C`、`Ctrl+V`，会生成 `文件名 (2).扩展名` 形式的副本。
- 在同一窗格或相同目录内拖放会被视为无操作，不再弹出同名冲突提示。
- 选中单个文件后，右键“打开方式（H）”会显示 Windows 原生“打开方式”窗口；文件夹不启用此项。
- 文件列表获得焦点时按 `Backspace` 等同于点击“上级目录”。
- 文件列表获得焦点时按 `Enter` 会进入所选文件夹；选中普通文件时按系统默认程序打开。

## 全局设置

从“选项 → 全局设置”可以调整：

- 登录 Windows 后是否自动启动当前这份 MYTC。
- 普通删除移到回收站前是否显示确认窗口。

永久删除不受该选项影响，始终显示确认窗口。绿色版移动到其他目录后，如果启用了开机启动，请重新保存一次全局设置以更新启动路径。

## 地址栏快速导航

按 `Alt+D` 后，活动窗格的地址栏获得焦点，原路径文字全部选中。此时可直接按 `Ctrl+V` 粘贴其他地方复制的路径，再按 `Enter` 跳转。

地址栏既支持从网页、文本框等位置复制的文本路径，也支持 Windows 文件剪贴板中的单个文件或文件夹路径；如果复制了多个文件，则取第一个路径。

## 固定到任务栏

- MYTC 会向 Windows 提供稳定的应用身份、重新启动命令、显示名称和图标。
- 启动 MYTC 后，右键任务栏上的 MYTC 图标，可使用 Windows 提供的“固定到任务栏”。
- 此菜单由 Windows Shell 生成；如果系统或单位策略禁止固定应用，MYTC 不会绕过该策略。
- 从 `T:` 等非本地位置固定后，之后从固定图标启动时仍可能出现 Windows 的非本地位置安全警告。

## 快捷方式

- 双击指向文件夹的 `.lnk` 会直接在当前 MYTC 窗格打开目标目录。
- 指向普通文件或程序的快捷方式仍按照 Windows 默认方式打开。

### 右键拖放与创建快捷方式

1. 在源窗格选中文件或文件夹。
2. 按住鼠标右键拖到另一个窗格后释放。
3. 从弹出菜单选择“复制到此处”“移动到此处”或“在当前位置创建快捷方式”。

创建的是 Windows 标准 `.lnk` 文件；如果目标位置已有同名快捷方式，会自动生成带 `(2)` 的新名称。

## 自定义右键菜单

右上角“右键菜单设置”可以隐藏、改名、调整内置项目顺序，或添加外部程序。

内置“复制完整路径”的行为：

- 选中文件时复制完整文件路径，例如 `T:\V2-包1.docx`。
- 选中文件夹时复制该文件夹完整路径，例如 `T:\素材`；盘符根目录保持为 `T:\`。
- 多选时复制多条路径，每行一条。
- 在列表空白处右键会清除选择，此时复制当前窗格目录。

### 右键菜单访问键和方案

- 在“菜单文字”中把 `&` 放到字母前即可设置访问键。例如 `复制完整路径（&A）` 在实际右键菜单中显示为“复制完整路径（A）”，A 带下划线；打开菜单后直接按 `A` 即可执行。
- 默认采用 Windows 风格两级菜单：打开右键菜单后按 `W` 展开“新建”，再按 `F` 新建文件夹。
- 右键菜单打开时会停用输入法组合，菜单操作在菜单关闭后才执行，避免中文输入法快速输入 `W`、`F` 时发生重入。
- “恢复默认”会恢复全部内置菜单项。
- 顶部“保存为方案”可以保存当前菜单文字、顺序、显示状态和外部程序；以后可从方案列表载入。

外部程序参数支持：

- `{path}`：首个所选项目
- `{paths}`：全部所选项目
- `{directory}`：当前窗格目录

变量展开时会自动加引号。

## v1.0.0 边界

- 支持本地盘、移动盘、映射盘和普通 UNC 路径；不把 FTP 或压缩包作为目录浏览。
- 外部程序改变文件后，必要时点击窗格刷新按钮。
- 暂不包含完整 Windows Shell 右键菜单、配置导入导出、搜索和自定义非四窗格布局。
- “撤销删除”只覆盖本次 MYTC 运行期间由 MYTC 执行的最近删除，不是跨程序、跨重启的完整文件操作历史。
- Win+E 桥接是当前用户登录会话中的轻量键盘钩子；如果桥接没有运行，Win+E 会安全回退到 Explorer。
- 包内 SHA-256 用于发现损坏或文件被替换，当前个人版尚未使用商业代码签名证书。
