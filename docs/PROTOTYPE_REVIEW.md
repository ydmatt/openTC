# MYTC 原型验证记录

日期：2026-07-27  
原型：`prototype/index.html`  
浏览器：本机 Microsoft Edge，无网络依赖

## 验证结果

- 四个窗格正常渲染。
- 2×2 布局在 1600×1000 和 1366×768 下无页面级横向或纵向溢出。
- 点击其他窗格后，活动窗格和上一个活动窗格组成新的活动/目标关系。
- 固定目录标签从临时路径再次激活后，正确回到固定路径。
- 点击大小列后显示升序标志并执行排序。
- `Ctrl+D`、`P` 连续按键正确触发原型命令。
- 标书工作区和 YouTube 工作区可以切换。
- 临时最大化时只显示一个窗格，恢复后回到四窗格。
- 文件行右键可以打开自定义右键菜单。
- 浏览器控制台和页面脚本无错误。

## 发现并修复

初次验证时，在非活动窗格内直接点击标签或排序列会先触发整个窗格重绘，从而吞掉原点击。

修复方式：

- 窗格首次获得焦点时只更新活动/目标样式，不重建 DOM。
- 标签、排序等具体动作完成后再按需重绘。

复验通过。

## 原型限制

- 不读取真实文件系统。
- 不执行真实复制、移动、删除和外部程序命令。
- 文件图标和内容是界面示意。
- 原型用于确认信息密度和交互结构，不代表最终 WPF 视觉细节。
