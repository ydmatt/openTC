# MYTC

MYTC 是一个供个人使用的 Windows 高效率多窗格资源管理器。它借鉴 Total Commander 的键盘效率和文件操作方式，并采用类似 Q-Dir 的默认 2×2 四窗格工作区。

## 主要场景

- 标书工作：同时打开项目、素材、临时文件和 AI 生成文件等目录，在窗格之间频繁查看、打开、复制和移动。
- YouTube 视频制作：在项目、常用工具、视频素材、图片素材和各类输出目录之间快速切换。

## 第一版范围

- 支持 Windows 10/11。
- 免安装、绿色便携运行。
- 默认 2×2 四窗格，每个窗格独立浏览。
- 窗格大小可调整，当前窗格可临时最大化并一键恢复。
- 每个窗格有独立地址栏、盘符快速切换下拉菜单、标签栏和文件列表。
- 每个窗格支持多个标签。
- 标签标题可以固定为用户自定义标题。
- 普通标签保持最后一次操作位置。
- 固定目录标签每次点击或重新激活时返回预设目录。
- 标签栏空白处双击新建标签，中键点击标签关闭；标签右键菜单可将当前目录名和路径固定到标签。
- 标签可从右键菜单完整复制到目标窗格，也可直接拖到另一个窗格复制；标签右键菜单支持隐藏、改名、排序、恢复默认及命名方案。
- 软件启动时恢复上次关闭时的窗格、标签、目录和布局。
- 工作区布局可以保存并通过加载不同设置切换。
- 提供 Windows 资源管理器的基本文件操作。
- 支持系统默认程序打开文件、窗格内外拖放和系统剪贴板。
- 文件夹快捷方式在当前窗格内打开；同目录 `Ctrl+C`、`Ctrl+V` 会创建自动重命名的副本。
- 文件列表支持名称、修改日期、类型、大小等详细信息列，并可点击列标题排序。
- 文件和文件夹显示 Windows Shell 默认关联图标。
- 顶部保留“文件、编辑、查看、选项、信息”传统菜单；F5/F6 等操作按钮归入可隐藏工具栏。
- 在同一默认方案中同时提供 Windows 剪贴板式快捷键和 Total Commander 目标窗格式快捷键；一个命令还可以绑定多个快捷键。
- 支持单键、组合键和连续按键序列；快捷键仅在 MYTC 内生效。
- 用户可以逐项修改快捷键。
- 右键拖放到其他窗格后可选择复制、移动或在目标位置创建 Windows 快捷方式。
- 右键菜单支持 Windows 风格两级“新建（W）→ 文件夹（F）”、`&字母` 访问键，并支持恢复默认及保存/载入命名方案。
- 文件右键菜单提供 Windows“打开方式”；`Backspace` 返回上级目录，`Ctrl+D` 也可移到回收站。
- 文件列表按 `Enter` 打开文件或进入文件夹。
- “选项 → 全局设置”可控制开机启动和普通删除确认；永久删除始终二次确认。
- 普通删除进入回收站，并可撤销当前 MYTC 会话内最近一次删除；重名和批量失败提供明确处理结果。
- 右键菜单支持调整内置菜单项及添加带变量的外部程序命令。
- 工作区保存完整布局、标签、目录、排序状态及活动/目标窗格；快捷键和右键菜单作为全局设置。

## 当前状态

生产修订版 `v1.0.13` 已于 2026-07-31 完成开发和本机隔离验收。当前生产线保留 `Win+E` 启动 MYTC，但不再接管 Windows 资源管理器内部的文件夹打开方式：

- 映射共享盘和 UNC 路径不再依赖不可用的 Windows 回收站；普通删除改为移动到同一共享上的隐藏 `.MYTC-RecycleBin`，当前会话可可靠撤销。
- `Backspace` 返回上级目录或 `Enter` 进入文件夹后，即使刷新夺走焦点，无修饰键 `↑` / `↓` / `Enter` / `Backspace` 会持续回到刚才的文件窗格；不会只响应第一下按键。
- 鼠标切换窗格后，连续键盘导航立即跟随新的活动窗格，不会继续操作切换前的窗格。
- `Shift+↑` / `Shift+↓` 从当前文件开始连续选择，并可持续扩展或收缩选择范围。
- 任务栏身份按安装路径隔离，E 盘安装不会再被归并到旧 F 盘安装的固定项。
- 标签拖动改用窗格级鼠标跟踪，可把标签拖到任意其他窗格并复制。
- Win+E 桥接会先暂存 Windows 键，确认 `Win+E` 后整组拦截，避免开始菜单或桌面遮罩闪现；其他 Win 快捷键仍正常重放。第二实例在转发前授权主实例置前，主窗口另有输入线程前景切换兜底。
- 在 Windows 资源管理器中双击文件夹或按 `Enter` 始终留在资源管理器；更新到本版本后，旧版遗留的文件夹默认关联会自动安全恢复，已启用的 Win+E 桥接保持不变。
- 主窗口首次显示前按当前显示器工作区和 DPI 自适应，低分辨率/高缩放下标题栏最小化、最大化和关闭按钮保持可见。
- “文件 → 管理工作区方案”可导入、导出、删除命名工作区；同名导入会自动生成新名称，不覆盖现有方案。
- 每次加载或保存命名工作区后，该方案会成为下次启动的默认工作区；也可用 `MYTC.exe /work` 或 `MYTC.exe --workspace work` 直接启动指定方案。
- “查看”中可独立显示或隐藏操作工具栏、工作区工具栏和右上设置工具栏；设置会自动保存。
- 界面设置写入改为串行并使用唯一临时文件，避免快速切换工具栏时出现 `ui-preferences.json.tmp` 被占用。
- 在当前活动窗格直接连续输入名称片段（例如 `nfc` 或 `甘肃`）即可快速定位；支持大小写无关的英文和输入法提交后的中文名称，优先定位文件夹，随后才匹配普通文件；同类中优先精确开头匹配，再匹配名称中间片段。
- 同目录右键拖放会显示操作菜单，可选择“复制到此处”创建自动重命名副本，或“在当前位置创建快捷方式”；跨目录右键拖放仍可复制、移动或创建快捷方式。
- 固定标签始终显示其固定时设置的标题（未设置自定义标题时显示固定目录名）；普通标签始终随当前目录名称变化。
- 输入定位得到多个匹配文件夹后，可用 ↑ / ↓ 在匹配项之间循环切换。
- 进入子目录后按 Backspace 返回，文件列表会重新选中并聚焦刚才进入的子目录。
- 工作区、设置工具栏均隐藏时，顶部仅显示“4 MYTC”的黑色边栏会同时折叠，不再保留无功能空白高度。

验证结果：

- Release 全量自动化测试：61/61 通过。
- STA WPF 冒烟测试在 `Backspace` 后向真实焦点元素发送 `↓`，验证选择从第一项移动到第二项，并覆盖标签跨窗格复制等主要交互。
- 自管共享盘回收区在隔离沙箱完成文件和目录的删除、还原、重名保护及清理测试；本机 `T:` 已确认是可用的 `Network` 映射盘。
- 发布版黑盒测试确认第二实例目录请求转交主窗口、正常关闭保存目标目录；成品 Win+E 钩子能安装并由恢复信号退出。
- 外部更新器黑盒模拟升级：返回 0，完整替换、旧版备份、日志、`data` 保留和更新器临时宿主清理均通过。
- 自包含绿色版已在 Windows 10 上成功启动，不依赖系统预装 .NET；发布包不含 `data`。
- v1.0.13 主程序和维护程序文件版本均为 `1.0.13.0`；发布包的最终投递路径和 SHA-256 会记录在 `PROJECT_MEMORY.md`。
