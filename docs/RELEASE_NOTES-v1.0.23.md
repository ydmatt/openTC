# MYTC v1.0.23 发布说明

## 本版内容

- 普通左键拖放支持多选文件、文件夹或混合选择直接拖入列表中的同级文件夹。
- 拖入文件夹时默认移动；按住 `Ctrl` 执行复制，按住 `Shift` 强制移动。
- 拖到空白处继续使用原有当前目录复制/移动行为。
- 右键拖放到同级文件夹时，复制、移动和创建快捷方式菜单均以该文件夹为目标。
- 目标解析只接受当前目录的直接子文件夹，不接受任意外部路径作为悬停目标。

## 升级方式

把 `MYTC-v1.0.23-win-x64.zip` 放入 `T:\mytc-updates`，在 MYTC 中选择“选项 → 从升级包升级”。升级器会保留安装目录下的 `data`，不会覆盖个人配置。
