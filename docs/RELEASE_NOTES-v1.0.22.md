# MYTC v1.0.22

## 本版新增

- 工作区缺省图标库增加数字 `1–9` 和字母 `A–Z`，共 35 个徽标。
- 工作区管理可以手动选择任意徽标，也可选择“自动”按工作区名称匹配。
- 继续保留“默认 TC”无徽标选项。

## 兼容性

- 原有工作区的 `1`、`W` 设置继续生效。
- 工作区配置格式没有变化，升级不会改动或覆盖现有 `data`。

## 验证

- Release 自动化测试 81/81 通过。
- STA 界面测试已验证全部 35 个自动/手动徽标、35 个任务栏徽标实际渲染及 37 项图标选择列表。
- 发布包启动、多工作区并行和外部更新器黑盒测试通过。
- 升级 ZIP SHA-256：`6323C6D27CF171F6FCFE3A417FA5DB39D0FEFC682DDDEF8EE1FC221EF9334425`。

## 升级

在 MYTC 中选择“选项 → 从升级包升级”，选择 `MYTC-v1.0.22-win-x64.zip`。
