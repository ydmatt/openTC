# MYTC 第一版开发路线

状态：v0.1.0 的 M0—M5 已完成  
日期：2026-07-27

## M0：设计基线

状态：已完成。

目标：开发前把需求、架构、数据模型和交互闭环固定下来。

完成标准：

- 第一版需求冻结。
- 技术路线、数据结构和安全规则形成文档。
- 四窗格交互原型可操作。
- 用户确认后进入 M1。

## M1：可运行四窗格骨架

状态：已完成。

目标：得到第一条可运行垂直切片，不含破坏性文件操作。

范围：

- 建立 WPF 解决方案和测试工程。
- 实现布局树及默认 2×2 窗格。
- 实现活动窗格、目标窗格切换。
- 实现每窗格地址栏、盘符菜单和详细信息列表。
- 实现后台目录枚举、刷新和基本错误状态。
- 实现名称、日期、类型、大小排序。

完成标准：

- 可同时浏览四个真实目录。
- 切换目录时 UI 不冻结。
- 盘符菜单可切换本地盘、移动盘和映射盘。
- 不存在、无权限、网络断开都有明确提示。

## M2：标签和工作区

状态：已完成。

范围：

- 多标签、新建、关闭、排序、重命名。
- 普通标签最后位置。
- 固定目录标签。
- 前进、后退、上级。
- 完整工作区保存和加载。
- 崩溃恢复、配置备份和版本迁移。

完成标准：

- 关闭重开后状态与需求一致。
- 标书和视频两个工作区可以独立保存和切换。
- 配置损坏测试能够从备份恢复。

## M3：安全文件操作

状态：已完成；当前采用托管后台操作服务，`IFileOperation` 留作后续增强。

范围：

- 统一异步文件操作执行器。
- 复制到目标、移动到目标、新建、重命名、回收站删除、永久删除。
- 冲突选择、进度、取消、部分失败清单。
- Windows 剪贴板复制、剪切、粘贴。

完成标准：

- 所有自动化测试只使用临时沙箱。
- 普通删除正确进入回收站。
- F5/F6 与 Ctrl+C/Ctrl+X/Ctrl+V 保持不同但正确的语义。
- 操作完成后相关窗格可靠刷新。

## M4：拖放、快捷键和右键菜单

状态：已完成。

范围：

- 窗格内外 Windows 文件拖放。
- Windows + TC 合并快捷键。
- 单键、组合键和连续键序列。
- 冲突检测、候选提示和快捷键编辑器。
- 自定义右键菜单和外部程序命令。

完成标准：

- 能与桌面、资源管理器和常用应用双向拖放。
- 连续按键超时、取消和冲突均有测试。
- 外部命令参数正确分隔，不发生未授权 Shell 拼接。

## M5：绿色发布与日用验收

状态：工程验收已完成；进入用户真实日用阶段。

范围：

- win-x64 自包含目录发布。
- 首次启动默认工作区。
- 日志轮换、异常恢复和设置备份。
- 键盘可访问性和高 DPI 验证。
- Win10/Win11 实机回归。

完成标准：

- 解压后直接运行，不要求预装 .NET。
- 整个目录复制到其他位置后，工作区和设置可以随之迁移。
- 完成 `docs/REQUIREMENTS.md` 的完整验收场景。
- 连续日用测试未发现数据损坏或误删除。
