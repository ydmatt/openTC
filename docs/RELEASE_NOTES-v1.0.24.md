# MYTC v1.0.24 发布说明

## 本版内容

- 激活标签会自动刷新当前目录；重复点击当前标签也会刷新。
- 盘符下拉项显示可用空间/总容量，并用占用率进度条着色；可用空间低于 10% 时红色警示。
- 文件列表空白处支持鼠标拖框选择可见文件和文件夹。
- 多选拖放保存真实选择集合，支持一次拖放多个文件、文件夹或混合项目。

## 升级方式

把 `MYTC-v1.0.24-win-x64.zip` 放入 `T:\mytc-updates`，在 MYTC 中选择“选项 → 从升级包升级”。升级器会保留安装目录下的 `data`，不会覆盖个人配置。
