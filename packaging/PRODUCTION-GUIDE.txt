openTC 生产版使用说明
===================

一、首次安装

1. 请把整个 openTC 文件夹放到本机固定磁盘，例如：
   E:\port\openTC

2. 不要从 T: 盘、网络共享或映射网络盘直接运行生产版。网络盘只用于存放升级 ZIP。

3. 如果要沿用旧版设置，请先关闭所有 openTC，再把旧版的 data 文件夹复制到新目录：
   E:\port\openTC\data

4. 启动 MYTC.exe（这是为旧版本升级保留的兼容文件名，窗口和产品名称显示为 openTC）。


二、接管普通文件夹和 Win+E

1. 在 openTC 中打开：
   选项 → Windows 默认文件夹接管与恢复

2. 也可以在 openTC 关闭时直接运行：
   MYTC.Maintenance.exe

3. 点击“注册为默认文件夹程序（含 Win+E）”。

接管范围：
- 普通文件夹和磁盘的默认打开动作
- Win+E

不会接管：
- Windows 桌面
- 任务栏
- 登录外壳
- explorer.exe 进程本身


三、恢复 Windows 资源管理器

无论 openTC 能否正常启动，都可以直接运行 MYTC.Maintenance.exe，
点击“恢复 Windows 资源管理器”。

恢复记录保存在：
%LocalAppData%\MYTC\shell\registration-backup.json


四、以后升级

1. 把新版 openTC-vX.Y.Z-win-x64.zip 放到：
   T:\mytc-updates

2. 在 openTC 中选择：
   选项 → 从升级包升级

3. 选择 ZIP。openTC 会先校验包内每个文件，再退出并由外部更新器替换程序。

升级器会：
- 保留安装目录中的 data 文件夹
- 在 %LocalAppData%\MYTC\updates\backups 保存旧版程序备份
- 失败时自动回滚
- 成功后自动重启 openTC

不要自行解压升级 ZIP 覆盖正在运行的程序。


五、重要说明

- 第一次从 0.1.7 升到 1.0.0 时，旧版还没有“从升级包升级”菜单，
  因此需要按“首次安装”步骤手动复制一次。此后的版本可在程序内升级。
- 升级包清单和文件 SHA-256 用于发现损坏或文件被替换；当前个人版尚未使用商业代码签名证书。
- 在映射共享盘或 UNC 共享中执行“移到回收站”时，openTC 会把项目移动到
  同一共享根目录下的隐藏目录 .MYTC-RecycleBin；这样当前会话内仍可使用
  “撤销删除”，且不需要跨网络复制大文件。请勿手动移动或删除该隐藏目录。
